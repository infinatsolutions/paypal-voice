# PayPal OpenAPI specifications (third-party)

The `.json` files in this folder are PayPal's official OpenAPI 3 specifications, copied unmodified from
<https://github.com/paypal/paypal-rest-api-specifications> (see `SOURCE.txt` for the commit). They are
© PayPal and licensed under the Apache License 2.0; a copy is in `LICENSE` in this folder.

PayPal Voice uses them to check every request it builds against PayPal's published contract
(`paypal_voice/contracts.py`). They are not covered by this project's MIT license.
